# 11 · Checklist TREC

> Marca les caselles a mesura que avances. Les tres primeres seccions són les
> que demana la guia del centre; les dues últimes són específiques d'aquest
> projecte.

## 1. Planificació

- [x] Tinc clars els criteris d'avaluació (seguiment 30 %, dossier 30 %, oral 40 %).
- [x] He triat el tema i el títol provisional.
- [x] He fixat l'objecte d'estudi, la pregunta i les hipòtesis.
- [x] Tinc els objectius generals i específics per escrit.
- [x] He triat la metodologia (projecte tecnològic + mètode experimental).
- [x] Tinc un pla de treball amb cronograma.
- [x] He fet la primera entrevista amb el tutor (no avaluable).
- [x] Tinc el **quadern de seguiment** obert.

## 2. Documentació

- [ ] He llegit les dues guies del centre (`docs/GUIA TREC 25-27.docx.pdf`,
      `docs/Guia-practica-per-fer-un-bon-TR-BTX- (1).pdf`).
- [ ] Tinc les fonts anotades amb dades completes (autor, any, URL, data).
- [ ] He separat el que és **cita** del que és **paràfrasi**.
- [ ] Tinc el marc teòric estructurat en temes i subtemes.
- [ ] He identificat els buits d'informació.
- [ ] Tinc la bibliografia en un sol sistema de citació.

## 3. Redacció del document

### Portada i inici

- [ ] Títol clar, concret i complet.
- [ ] Nom i cognoms, curs, tutor, centre i localitat.
- [ ] Full en blanc després de la portada.
- [ ] **Abstract** en català i anglès (pàgina 1).
- [ ] Índex amb tots els capítols i subapartats, amb pàgina.
- [ ] Agraïments (opcional), després de l'índex.

### Introducció

- [ ] Objecte del treball.
- [ ] Motivació personal.
- [ ] Rellevància.
- [ ] Hipòtesi.
- [ ] Objectius.
- [ ] Metodologia.
- [ ] Estructura de la memòria.

### Cos

- [ ] Marc teòric **més curt** que el marc pràctic.
- [ ] Capítols i subapartats equilibrats.
- [ ] Numeració 1. / 1.1. / 1.2. …
- [ ] Màxim quatre nivells.
- [ ] Cada afirmació té dada, cita o referència.
- [ ] No hi ha repeticions innecessàries.
- [ ] Les figures i taules estan numerades i comentades al text.
- [ ] Els peus de figura són coherents.

### Conclusions

- [ ] Responen la pregunta de recerca.
- [ ] Diuen quins objectius s'han assolit i quins no.
- [ ] Expliquen les dificultats.
- [ ] Valoren la metodologia.
- [ ] Inclouen línies futures.
- [ ] L'opinió personal és breu i argumentada.
- [ ] No repeteixen el treball.

### Bibliografia

- [ ] Hi són totes les fonts consultades i usades.
- [ ] Cada font té ressenya completa i comentari d'ús.
- [ ] Ordre alfabètic.
- [ ] Un sol sistema de citació.
- [ ] No hi ha fonts que no s'hagin usat.

### Annexos

- [ ] Diari de recerca.
- [ ] Guia de muntatge i esquemes electrònics (annex 14).
- [ ] Codi font complet i enllaç al repositori (annex 15).
- [ ] Logs representatius (no tots).
- [ ] Taules de mesures completes.
- [ ] Captures o diagrames addicionals.
- [ ] Numeració romana (ANNEX I, II…).
- [ ] Figuren a l'índex general.

## 4. Aspectes formals

- [ ] A4, una cara.
- [ ] Times New Roman 12 / Arial 11 / Verdana 11.
- [ ] Taules a cos 9.
- [ ] Interlineat 1,5.
- [ ] Marges de 2,5 cm als quatre costats.
- [ ] Text justificat.
- [ ] Sense sagnia; doble espai entre paràgrafs.
- [ ] Pàgines numerades a baix a la dreta.
- [ ] Portada i índex sense número.
- [ ] Títols i subtítols amb el mateix estil.
- [ ] Cites textuals entre cometes i amb font.
- [ ] Corrector ortogràfic passat.
- [ ] Relectura final en paper.

## 5. Checklist tècnica del prototip

- [ ] La placa arrenca i mostra la cara.
- [ ] El micro USB es detecta (espere 25 s si cal).
- [ ] Només hi ha **una** instància del programa en marxa.
- [ ] El log mostra la versió i l'empremta correctes.
- [ ] La conversa per veu funciona en català/castellà.
- [ ] La memòria recupera un record conegut.
- [ ] L'agenda crea, consulta i reprograma una cita.
- [ ] El canvi núvol/local funciona per veu.
- [ ] Sense xarxa, el local respon.
- [ ] Edge TTS sona; si falla, Piper entra.
- [ ] La cara no es congela ni allarga els ulls.
- [ ] Les 24 suites de prova passen (o se sap quines no).
- [ ] Hi ha una còpia recent al PC.
- [ ] Hi ha un **vídeo de reserva** de la demo.

## 6. Checklist de la defensa oral

- [ ] Guió de 20 minuts assajat i cronometrat.
- [ ] 12-14 diapositives, una idea per diapositiva.
- [ ] Cap diapositiva llegida literalment.
- [ ] Demo assajada amb el mateix ordre.
- [ ] Vídeo de reserva preparat.
- [ ] Xifres clau memoritzades (1,6 s; 8,75 s; 150 ms; 4/8).
- [ ] Respostes preparades per a les 10 preguntes probables.
- [ ] Placa, cables, alimentació i altaveu comprovats.
- [ ] Log i taules en paper per si falla la pantalla.
- [ ] Tancament assajat (10 segons).

## 7. Abans de cada entrevista amb el tutor

- [ ] Portar el quadern de seguiment actualitzat.
- [ ] Portar una novetat concreta (mesura, demo o document).
- [ ] Anotar els acords i les tasques.
- [ ] Demanar feedback sobre el que no t'agrada.
- [ ] Fixar la data de la següent entrevista.

## 8. Lliurament

- [ ] Memòria impresa i enquadernada.
- [ ] Annexos enquadernats amb la memòria o a part, amb portada identificativa.
- [ ] Còpia digital (PDF) desada.
- [ ] Còpia de seguretat al PC i al núvol.
- [ ] Comprovat el termini i el lloc de lliurament.
- [ ] Conservat el rebut o el justificant.

> La guia recorda que **no es pot aprovar** si l'expressió escrita no és
> adequada, i que cada falta resta 0,1 punts fins a un màxim de 2. La relectura
> no és opcional.
